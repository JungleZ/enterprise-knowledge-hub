作品原件与远程部署说明（InnoRAG）

本作品为可运行的企业知识库智能问答系统，源代码与线上演示如下。

1. 源代码仓库（作品原件）

  • GitHub 仓库：https://github.com/JungleZ/enterprise-knowledge-hub
  • 技术栈：Go（后端）+ MeiliSearch + PostgreSQL/pgvector + React（前端），Docker Compose 一键编排。
  • 主要目录：
  • backend/：检索、重排、误检门槛、LLM 生成、企微接入等核心服务
  • frontend/：Web 聊天界面与知识库管理
  • docker-compose.yml：本地/生产一键部署

2. 远程部署环境

  • 生产环境已部署于公网服务器：8.215.92.160（Docker Compose 编排 backend / frontend / MeiliSearch / Postgres）。
  • 部署方式：仓库内置 docker-compose.yml，执行 docker compose up -d 即可拉起全部服务；知识库更新后调用后台接口 /api/admin/reindex 一键重建向量索引。

3. 访问方式

  • Web 演示界面：http://8.215.92.160:3002
  • 后端 API 基址：http://8.215.92.160:8081
  • 演示账号：admin@demo.local / demo123

4. 功能演示建议（供评委验证）

类型 示例问题 预期表现
命中作答（带引用） 年假怎么申请 / 报销流程是什么 / 请假需要谁来审批 基于知识库作答，并标注引用来源
离题拒答 公司食堂在几楼 / WiFi密码是多少 / 年终奖什么时候发 明确回复“暂无相关答案”，不编造
知识库缺失拒答 产假是多少天 / 陪产假有几天 检索无可靠依据，如实拒答
